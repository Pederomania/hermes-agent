# Skill: Research

Este skill proporciona herramientas para investigación web.

## Uso

Para buscar información, usa la herramienta `web_search` con tu query:

```
Query: buscar información sobre X
Tool: web_search
```

## Fuentes confiables

### Documentación oficial
- Python: docs.python.org
- JavaScript: developer.mozilla.org
- Rust: doc.rust-lang.org

### APIs
- RapidAPI
- Public APIs

### Comunidades
- Stack Overflow
- Reddit
- Hacker News

##Tips para research efectivo

1. **Queries específicas** -"Cómo hacer X en Python" en lugar de "Python"
2. **Incluir version** -"Python 3.10" para versión específica
3. **Busca ejemplos** -"Python async example"
4. **Usa quotes** - Para búsqueda exacta
